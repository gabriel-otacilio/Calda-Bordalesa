## Desenvolvimento de uma calculadora bordalesa pra fins de estudo e pratica de java e Spring boot;

- desenvolvido usando:
    - java
    - maven
    - Spring boot com algumas 'bibliotecas':
      - Spring boot starter web
      - Spring boot starter data jpa
      - Spring boot starter test
      - Spring boot devtools
      - React-js


- Usando arquitetura em camadas
- Usando o banco de dados MySQL, que esta rodando localmente via container docker

Existe também a pasta etapas que contem os passos que fiz para criar o projeto e uma espécie de tutorial para entender um pouco das tecnologias que usei para o desenvolvimento do trabalho

---

Nessa branch eu pretendo realizar o desenvolvimento do projeto usando agora a biblioteca React do javascript. Afim de ser uma aplicação simples para praticar a conexão entre o front e o back de forma dinamica e rapida
